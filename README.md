# 엔트리 챗봇

말로 설명하면 엔트리(Entry) 작품 파일(`.ent`)을 만들어 주는 챗봇이에요.
일반 질문에도 답해요. 서버 없이 브라우저에서만 돌아가요.

## 사용법

1. 사이트를 열어요. (또는 `index.html`을 내려받아 더블클릭)
2. 오른쪽 위 **설정**에서 사용할 AI(Gemini 또는 Groq)를 고르고 **내 API 키**를 넣은 뒤 저장해요.
   - Gemini 무료 키: https://aistudio.google.com/apikey
   - Groq 무료 키: https://console.groq.com/keys
3. 만들고 싶은 작품을 말해요. 예: `방향키로 움직이는 빨간 공 만들어줘`
4. 답변 아래의 **.ent 받기** 버튼으로 파일을 받아 엔트리 오프라인 에디터에서 열어요.
5. 이어서 `공을 초록색으로 바꿔줘`처럼 말하면 고쳐 줘요.

## 키는 안전한가요?

- 키는 이 저장소에 들어 있지 않아요.
- 내가 넣은 키는 **내 브라우저에만** 저장되고, 고른 AI 서비스(Google 또는 Groq)로만 전송돼요.
- 사용량은 각자 자기 키로 계산돼요. 결제 수단을 연결하지 않은 무료 키를 쓰는 걸 추천해요.
- 개인정보나 비밀번호는 입력하지 마세요.

## 지원하는 것

이동, 회전, 말하기, 반복, 조건, 변수, 신호, 복제본, 장면, 모양 바꾸기, 효과음, 효과, 계산, 질문과 대답, 3D처럼 보이는 효과(원근법)

## 못 하는 것

리스트, 함수, 직접 만든 이미지·소리 파일, 글상자, 하드웨어 블록, 진짜 3D.
오브젝트 모양은 도형(원, 네모, 세모)과 색깔만 돼요.

## 알아 둘 점

엔트리 블록의 이름과 설정값은 기억에 의존해 만든 거라, 파일이 안 열리거나 일부 블록이 다르게 나올 수 있어요.
문제가 생긴 작품의 `.ent` 파일과 함께 이슈를 남겨 주시면 고치는 데 큰 도움이 돼요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| Failed to fetch | VPN과 광고 차단을 끄고 다시 시도 |
| 모델 오류 | 설정의 모델 이름을 서비스 최신 이름으로 변경 |
| 이용자가 많다 | 잠시 뒤 다시 보내기 (자동 재시도 있음) |
| 한도 초과 | 1분 정도 기다리거나 다른 AI로 바꾸기 |
